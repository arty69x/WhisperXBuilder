# WPX Studio OS

A brand-new production project built with Next.js 16, React 19, TypeScript, App Router, and Tailwind CSS v4.

## Getting started

1. Install dependencies: `npm install`
2. Start development: `npm run dev`
3. Validate production readiness: `npm run lint && npm run typecheck && npm run build`

See `docs/architecture.md` for the clean architecture and feature-based folder layout.
