# WPX Studio OS Architecture

- `app/`: Next.js App Router routes and layouts.
- `features/`: Feature modules with local components and business logic.
- `components/`: Shared UI and shell components.
- `lib/`: Framework-agnostic services and configuration.
- `hooks/`: Shared React hooks.
- `types/`: Shared TypeScript contracts.
- `styles/`: Global Tailwind CSS v4 entry points.
